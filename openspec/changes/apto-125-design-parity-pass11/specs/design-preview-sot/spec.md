## MODIFIED Requirements

### Requirement: Account list matches preview row chrome

The accounts table SHALL expose an "Open" column header for the row chevron link (not screen-reader-only).

### Requirement: Account detail header matches list SLA visualization

The account detail hero SHALL use the same bar-only SLA segment visualization as the accounts list.

### Requirement: Inventory table uses preview column defaults

Persisted inventory column selections SHALL normalize to `INVENTORY_PREVIEW_DEFAULT_COLUMNS` when loading saved searches unless the user expands columns in-session.
