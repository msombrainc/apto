# Apto web (Week-1)

Vite + React shell for account search/create.

## Demo login

Use **demo** / **demo** (client-side stub only — not production auth).

## Local dev

```bash
# API on :8080 (docker compose or dotnet run)
cd apps/web && npm install && npm run dev
```

Vite proxies `/api` to `http://localhost:8080`.
